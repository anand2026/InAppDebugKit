# Changelog

## 1.0.0
- API request inspector (URLSession, incl. custom sessions), with search, filters, cURL, copy and share
- Header redaction and captured-host filter
- Crash capture (signals + Objective-C exceptions) with next-launch alert
- Automatic screen tracking for SwiftUI (incl. AnyView, sheets, full-screen covers) and `.debugScreen(_:)`
- Manual WebSocket event logging
- Floating bubble, Settings & App Info, UserDefaults viewer
